# Land Carrier Project - Troubleshooting Guide

## Critical Issue: File Permission Errors (February 2025)

### Quick Diagnosis
If you see errors like:
- `Cannot create file 'res://.godot/imported/...'`
- `Cannot save scene to file`
- `Check user write permissions`
- `Failed loading resource`

**You have a file permission problem.** Follow the steps below to fix it.

---

## Solution Steps

### Step 1: Close Godot Completely
Make sure Godot Editor is fully closed before proceeding.

### Step 2: Fix Permissions

#### Windows:
1. Navigate to your project folder in File Explorer
2. Right-click the project folder → **Properties**
3. Go to the **Security** tab
4. Click **Edit** → Select your user account (or Add if not listed)
5. Check **Full control** in the Allow column
6. Click **Apply** → Choose **Apply to all subfolders and files**
7. **IMPORTANT:** Go to **General** tab → Uncheck "Read-only" if checked
8. Click **Apply** → Apply to all files

#### Linux/macOS:
```bash
# Navigate to project directory
cd /path/to/Land-Carrier-Project

# Fix permissions
chmod -R u+rwX .
chmod -R u+rwX .godot/

# If you still have issues, check ownership
ls -la .godot/
# If owned by root or another user:
sudo chown -R $USER:$USER .
```

### Step 3: Delete .godot Folder
```bash
# This folder will be regenerated by Godot
rm -rf .godot/        # Linux/macOS
rmdir /s .godot       # Windows Command Prompt
```
Or manually delete the `.godot` folder from File Explorer/Finder.

### Step 4: Check Disk Space
Ensure you have at least 2GB of free disk space. Check with:
- Windows: Right-click drive → Properties
- Linux/macOS: `df -h`

### Step 5: Reopen Project in Godot
1. Launch Godot Editor
2. Open the project
3. **Wait patiently** - Godot will reimport ALL assets (may take 5-10 minutes)
4. Watch the progress bar at the bottom of the editor
5. Do NOT close Godot during import

## Additional Checks

### Antivirus/Security Software
Some antivirus programs block Godot from creating files:
- **Windows Defender:** Add project folder to exclusions
- **Other AV software:** Check logs for blocked operations
- Temporarily disable AV to test (remember to re-enable!)

### File Location Issues
**Bad locations for projects:**
- ❌ `C:\Program Files\` (system protected)
- ❌ `C:\Windows\` (system protected)
- ❌ Inside OneDrive/Dropbox sync folders (can cause conflicts)
- ❌ Network drives (can have permission issues)

**Good locations:**
- ✅ `C:\Users\YourName\Documents\Projects\`
- ✅ `D:\GameDev\`
- ✅ `/home/username/projects/` (Linux)
- ✅ `~/Documents/Projects/` (macOS)

### Cloud Sync Warning
**DO NOT sync the `.godot` folder to cloud storage!**
- Dropbox, OneDrive, Google Drive, iCloud can corrupt this folder
- The `.godot` folder is now in `.gitignore` (excluded from version control)
- If using cloud sync, exclude `.godot/` in your sync settings

## Still Not Working?

### Run Godot as Administrator (Windows - Last Resort)
1. Close Godot
2. Right-click Godot executable
3. Select "Run as administrator"
4. Open your project

⚠️ **This should not be necessary** and may cause other issues. Only use if all else fails.

### Check File System Corruption
```bash
# Windows (Run as Administrator in Command Prompt)
chkdsk C: /F

# Linux
sudo fsck /dev/sdXY

# macOS
sudo fsck -fy
```

### Nuclear Option: Fresh Copy
If nothing works:
1. Backup your source files (scripts, scenes, models - NOT .godot folder)
2. Create a new folder in a safe location
3. Copy your assets there
4. Create new Godot project in that folder
5. Import your backed-up files

## Technical Details

### What is .godot/?
The `.godot` folder is Godot 4's cache directory containing:
- Imported/converted assets (textures, models, audio)
- Editor settings and metadata
- MD5 checksums for change detection
- Compilation cache

It can be deleted and regenerated at any time without data loss (though reimporting takes time).

### Why does this happen?
Common causes:
1. Project moved from another computer/user account
2. Extracted from ZIP without preserving attributes
3. Cloned from git without setting proper permissions
4. Parent folder has restrictive permissions
5. Antivirus interference
6. Disk errors or filesystem corruption
