Aircraft 3 model integration
============================

Author/export `Models/Aircraft_3/Aircraft_3.glb`. This source stays intact.
The aircraft scene loads `Models/Aircraft_3/aircraft_3_breakaway.glb`, generated by:

```powershell
& 'C:\Program Files\Blender 5.1\blender.exe' --background --factory-startup --python-exit-code 1 --python tools/build_aircraft3_breakaway.py
& 'C:\Godot\Godot_v4.6.2-stable_win64_console.exe' --headless --editor --path . --import --quit
```

The builder closes control-opening rims, generates matching capped wing/tail
fractures, and places control origins on their leading-edge hinges. Surface
coverage and fracture-cap checks run before export. The tail contains authored
closed shells meeting at edges; validation permits even-valence shell junctions
there, but requires no open debris boundaries. The cockpit's authored breakaway
piece is retained.

The exported GLB contains fixed landing-gear meshes. Its main wheel and support
are present only on positive X, so the builder mirrors them into the generated
model for the other side. Aircraft_3.tscn uses these Blender meshes for the
visible gear and hides the older Godot-added gear models. The existing Godot
wheel colliders and suspension remain aligned to the three Blender wheels.
Retraction is locked for this aircraft. A later retractable conversion would
require each authored gear assembly to be placed under its moving pivot.

The September 24 export contains only the negative-X elevator half. The builder
mirrors it into the same elevator mesh only while the entire source elevator is
on that side. Exporting a complete elevator supersedes this fallback.

`Aircraft3ControlSurfaces.gd` follows filtered SimpleAero inputs. Moving surfaces
are attached damage visuals: they hide when the associated section breaks, while
the capped fixed sections become physical debris. Both stabilizers failing also
detaches the existing common tail section.

Verification:

```powershell
& 'C:\Godot\Godot_v4.6.2-stable_win64_console.exe' --headless --path . --script res://Tests/Aircraft3ControlSurfacesSmoketest.gd
& 'C:\Godot\Godot_v4.6.2-stable_win64_console.exe' --headless --path . --script res://Tests/FixedWingPartDamageColliderSmoketest.gd
& 'C:\Godot\Godot_v4.6.2-stable_win64_console.exe' --path . --rendering-method forward_plus --script res://Tests/Aircraft3ControlSurfacesSmoketest.gd -- --render
```

Rendered poses and damage view are saved to `captures/aircraft3_controls/`.
